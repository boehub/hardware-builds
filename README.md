# Hardware Builds

Engineering designs and blueprints by **Ryan Boe**, a Computer Engineering student at Old Dominion University. Each project is documented as a set of dimensioned blueprint sheets, with 3D models, print/cut files and the calculations behind the design.

| Project | What it is | Status |
|---|---|---|
| [Filament Maker](filament-maker/) | 1 kg desktop machine that turns plastic scrap into 3D printer filament | Design complete (Rev B) |
| [Dual-Shaft Shredder](shredder/) | Shredder that cuts bottles and print scrap into flakes for the filament maker | Design complete |

## Repository layout

```
hardware-builds/
├── filament-maker/    README, images/, source/ (.pptx), models/, print-files/
└── shredder/          README, images/, source/ (.pptx), models/, cut-files/
```

## Tools used
Blender (3D assemblies, .fbx), PowerPoint (blueprint sheets), Python (generator and checker scripts), 3D printing (PETG/ASA).

See also: [vertical-wind-turbine](https://github.com/boehub/vertical-wind-turbine), a laser-cut vertical-axis rotor design.

*All projects are at the design stage unless a README says otherwise.*
